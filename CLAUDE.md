## Data and Build Model

- Static HTML generated by scripts; generated pages are **NOT committed** (history was
  rewritten in June 2026 after it reached 4 GB+). CI deploys `_site/` with
  `wrangler pages deploy` (`ops/deploy.md`). Tracked static pages: `solution.html`,
  `sitemap.xml`, `robots.txt`, `favicon.svg`.
- Private data repo `toouur/foursquare-data`: `checkins.csv`, `tips.json`, `photos.json`,
  `backfill.yaml/csv`, state files. `pix/` is CI-only; photos live in R2 under `/pix`.
- Pipeline: `transform.py -> metrics/ -> gen_* scripts + templates/*.tmpl -> *.html`.
  Orchestrator `scripts/build.py`. `metrics/` is a package (`stats`, `trips`,
  `trip_names`, `trip_insights`, `companions`, `shouts`, `milestones`, `coverage`, `venues`,
  `year_facts`, `life`); `import metrics` re-exports.
- Templates use `{{PLACEHOLDER}}` string substitution, not Jinja. A post-process pass fills
  `{{CTRY_CODE_JSON}}`, `{{CAT_ICON_JSON}}`, `{{SITE_CSS_LINK}}`, `{{CARTO_KEY}}`, PWA tags.
- Pages with whitelisted payloads (`_TRIPS_STATS_KEYS`, `gen_companions.SOCIAL_KEYS`):
  a key a template starts reading must be added to its whitelist or it arrives `undefined`.
- Canonical config lookups: `config/country_aliases.json`, `country_flags.json`,
  `category_icons.json`, `year_covers.json`, `companion_countries.json`,
  `companion_fixes.json`, plus the city configs below.

## Invariants (details in ops/)

- **Home is a timeline** (`settings.yaml` `trip_detection.home_history` + `home_city`).
  Anything measuring distance from / membership in home must be era-aware
  (`metrics.trips._home_at`, `metrics.stats.home_at_ts`); never read `home_city` alone.
  `home_venue_ids` is a union over all eras. → `ops/data-model.md`
- **Trip names are keyed by start ts** and self-heal (`trip_names.py:heal_trip_names`:
  MIGRATED / REMOVED / SUSPICIOUS — never guess). `trip_exclude/tags/start|end_overrides`
  are NOT healed. → `ops/data-model.md`
- **City pipeline priority**: `venue_fixes.json` (by venue_id) > `country_fixes.json` (ts)
  > `city_fixes.json` (ts; hex keys there are drift-suppression only, and it bypasses
  `city_merge`) > `city_merge.yaml` > blank-row centroid inference. Cities are
  NFC-normalized first. Gateways (borders/airports) are pinned to their PHYSICAL side with
  one venue_fixes entry. After an intentional city-set change refresh
  `config/city_count_baseline.json`. → `ops/data-model.md`
- **Late companion tags** go in `config/companion_fixes.json` (per checkin_id), never into
  `checkins.csv` — the monthly `--full` re-fetch overwrites it. → `ops/data-model.md`
- **D1 check-ins are append-only** (`INSERT OR IGNORE`, capped by copy count). Anything that
  changes an existing row needs its own reconcile pass (`--fix-overlaps-hours`, companion
  fixes, `rf*` backfill reconcile, `--venue-changes`). → `ops/d1.md`
- **D1 free-tier read/write budget is real** (hit on 2026-09-03). Prefer hash-gated
  (`sync_state`) and index-friendly queries (`id >= 'rf' AND id < 'rg'`, not `LIKE`); check
  `D1 usage this run:` output. → `ops/internals.md`
- **`/api/search` and `/api/feed` must never throw**; non-200 answers are never edge-cached.
- **Reconstructed (`rf*`) rows** come from `backfill.yaml`; `[geo_pinned]` in the shout keeps
  their geography through venue syncs. Never "pre-fix" a venue rename in `checkins.csv` by
  hand — the archive workflow diff must see the old name. → `ops/pipelines.md`, `ops/d1.md`
- **Py↔JS parity**: `collectCompanions()` in `functions/api/feed.js` mirrors
  `metrics.collect_companions`; bump the feed `_v=` tag when the tuple shape changes.
- **Nine workflows push the data repo** (8th `vivino.yml`, 9th `imdb.yml`); every commit step uses the BUG-014 bounded
  rebase-and-retry loop, no repo-wide `concurrency` group. → `ops/internals.md`
- **Last.fm raw layer is the truth** (`lastfm/scrobbles_<YYYY>.tsv`): repeats kept, every run
  replaces the last 14 days (late offline scrobbles), the year state is rebuilt from it. → `ops/pipelines.md`
- **Cloudflare via the MCP plugin is read-only** (OAuth "Read only"); every call still asks first.
  Never write to Cloudflare without explicit confirmation; writes stay in CI with its own tokens.

## Known Gotchas

- System Python may miss dependencies; use the Python314 path above.
- CSS `:visited` does not reliably support CSS variables; use literal colors.
- Chart/config brace-balance errors break pages silently; validate after edits.
- Companion name overrides require exact `with_name` matches.
- CARTO basemaps need `{{CARTO_KEY}}` (`settings.yaml` `basemap.carto_key` or env
  `CARTO_API_KEY`; domain-restricted, localhost needs its own). Keep OSM/CARTO attribution.
- The D1 binding `DB` is configured in the Cloudflare Pages dashboard; without it
  `/api/search` returns 503.
- Pages git auto-deploy must stay DISABLED. Pause switch: repo variable `UPDATES_PAUSED=true`.
